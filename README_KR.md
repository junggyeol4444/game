# 모바일 턴제 카드 전략 RPG

Unity 2022.3 LTS로 제작된 Android 및 iOS용 모바일 턴제 카드 전략 RPG 게임입니다.

## 프로젝트 개요

다음과 같은 기능을 갖춘 종합적인 카드 기반 전략 RPG:
- 7x5 그리드 기반 턴제 전술 전투
- 카드 수집 및 성장 시스템
- 카드 획득을 위한 가챠 메커니즘
- 탐험 및 랜덤 조우
- 방치형 게임 메커니즘 (훈련, 파견 임무)
- 퀘스트 시스템 (메인, 서브, 일일, 주간)
- NPC 상호작용을 포함한 이벤트 시스템

## 프로젝트 구조

```
Assets/
├── Scripts/
│   ├── Core/          # 핵심 게임 시스템
│   ├── Data/          # 데이터 모델 및 구조
│   ├── Systems/       # 게임 시스템 (전투, 카드, 가챠 등)
│   ├── Managers/      # 관리자 클래스
│   └── UI/            # UI 컨트롤러
├── Scenes/            # Unity 씬
├── Prefabs/           # 재사용 가능한 게임 오브젝트
├── Resources/         # 런타임 로드 에셋
└── StreamingAssets/
    └── Data/          # JSON 데이터 파일
        ├── cards.json
        ├── skills.json
        ├── quests.json
        ├── gacha_pools.json
        ├── encounters.json
        └── events.json
```

## 구현된 기능

### 1. 카드 시스템
- 카드 속성 (체력, 공격력, 방어력, 속도, 마법, 저항)
- 레벨업 및 경험치 시스템
- 카드 진화 메커니즘
- 카드에 스킬 할당
- 카드 조합을 위한 교배 시스템
- 카드 간 관계 시스템

### 2. 전투 시스템
- 7x5 그리드 기반 전술 전투
- 속도 기반 턴 순서를 가진 턴제 메커니즘
- 플레이어 행동: 이동, 공격, 스킬 사용, 방어
- 적 유닛을 위한 AI
- 상태 효과 및 버프/디버프
- 승리/패배 조건

### 3. 탐험 시스템
- 월드맵 탐험
- 랜덤 조우 시스템
- 고정 조우 위치
- 지역 전환
- 조우로부터 전투 초기화

### 4. 가챠 시스템
- 다중 가챠 풀 (일반, 프리미엄, 이벤트)
- 희귀도 기반 카드 획득
- 높은 희귀도 카드 보장을 위한 천장 시스템
- 단일 및 다중 뽑기 메커니즘
- 픽업 배너 지원

### 5. 퀘스트 시스템
- 메인 스토리 퀘스트
- 서브 퀘스트
- 일일 퀘스트 (자동 갱신)
- 주간 퀘스트 (자동 갱신)
- 퀘스트 목표 추적
- 보상 분배

### 6. 방치 시스템
- 카드 경험치를 위한 훈련 시스템
- 수동적 보상을 위한 파견 임무
- 방치 보상 누적
- 시간 기반 완료 추적

### 7. 이벤트 시스템
- NPC 상호작용 이벤트
- 던전 이벤트
- 선택 기반 게임플레이
- 요구사항 확인
- 보상 및 결과

### 8. 리소스 관리
- 골드, 젬, 티켓 화폐
- 재생되는 에너지 시스템
- 플레이어 레벨 및 경험치
- 저장/로드 기능

## 게임 시스템 문서

### 카드 데이터 구조
카드는 다음 속성을 가집니다:
- ID, 이름, 설명
- 희귀도 (일반부터 신화까지)
- 타입 (전사, 마법사, 레인저, 탱커, 서포터, 암살자)
- 레벨 및 경험치
- 스탯 (HP, 공격력, 방어력, 속도, 마법, 저항)
- 스킬
- 진화 경로
- 교배 호환성

### 전투 메커니즘
- 이동 범위 제한이 있는 그리드 기반 이동
- 속도가 턴 순서 결정
- 데미지 계산: `기본 데미지 - (방어력 / 2)`
- 스킬은 쿨다운과 마나 비용 보유
- 상태 효과는 여러 턴 동안 지속

### 가챠 확률
- 일반: ~40-50%
- 고급: ~25-35%
- 희귀: ~10-20%
- 영웅: ~3-8%
- 전설: ~1-3%
- 신화: ~0.1-1%

### 에너지 시스템
- 최대 에너지는 플레이어 레벨에 따라 결정
- 5분당 1 에너지 재생
- 전투 및 탐험에 필요

## 새로운 콘텐츠 추가

### 새로운 카드 추가
1. `Assets/StreamingAssets/Data/cards.json` 편집
2. 모든 필수 필드가 있는 새 카드 항목 추가
3. 스킬 및 스탯 할당
4. 희귀도 및 타입 설정

### 새로운 스킬 추가
1. `Assets/StreamingAssets/Data/skills.json` 편집
2. 스킬 속성 및 효과 정의
3. 마나 비용, 쿨다운 및 범위 설정

### 새로운 퀘스트 추가
1. `Assets/StreamingAssets/Data/quests.json` 편집
2. 목표와 함께 퀘스트 생성
3. 보상 및 전제 조건 정의
